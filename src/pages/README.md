# pages/

Pantallas completas de la aplicación. Cada pantalla vive en su propia subcarpeta (ej. `ListaProductos/`, `Checkout/`, `AdminCategorias/`), que agrupa el componente de página y lo que sea específico de esa pantalla.

Una página compone componentes de `components/`, consume datos vía `services/` y/o `context/`, y es a lo que apunta cada ruta definida en `routes/`.
